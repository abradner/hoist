# TUI redesign mockups

`mockups.html` is six screens of a proposed hoist TUI — matrix, tag picker, deploy confirm,
flight, rollout, and the in-flight panel — drawn as real terminal frames rather than described
in prose. Open it in a browser.

It is a **proposal, not a record**: nothing here is what hoist renders today. It exists so the
redesign starts from something concrete enough to argue with.

## What the frames are

Box-drawing characters, generated by `genframes.py` and checked for width rather than typed by
hand. Every earlier hand-drawn attempt had borders that were off by one somewhere, and an
off-by-one border is indistinguishable from a design opinion when you are reading a mockup. The
generator measures each line, so a frame that looks square is square.

If you change a frame, change it in `genframes.py` and regenerate. Editing the HTML directly
works right up until it doesn't.

## What the design is arguing for

Each screen carries its own reasoning inline, but the through-line is:

- **Containers, not a REPL.** hoist is a UI that happens to run in a terminal, so panes, borders
  and a visual hierarchy — not a scrolling log of command output.
- **Show what is in flight**, in full, when the terminal is big enough to hold it. A one-line
  "1 in flight" tells an operator nothing they can act on.
- **Impact over mechanism.** What an operator wants before pressing enter is "which commits am I
  shipping, and does one of them migrate the database", not a YAML diff. The commits, their
  messages, and an expandable long form are the interesting content; the manifest change is the
  mechanism that delivers it.
- **Use the library's own primitives.** lipgloss v2 has borders, `JoinHorizontal`/`JoinVertical`
  and a compositor; faking layout with padded strings is how the current screens got where they
  are.

## Placeholders

Every name here is invented — `my-gitops`, `me`, `ghcr.io/example/…`, `app-staging`,
`app-production`. This repo is public and its docs name no real repo, operator, cluster or app.
The substitutions are length-neutral so the measured frame widths still hold.
